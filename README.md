# Java Academy — GitHub Pages Edition

Русскоязычный интерфейс, 12 модулей / 60 англоязычных уроков, тесты, личный кабинет, авторизация Supabase.

## Быстрый запуск

1. Создайте новый GitHub-репозиторий. Рекомендуется сначала проверить сайт на временном адресе GitHub Pages, не заменяя текущий ymnichka.fun.
2. Загрузите **содержимое** ZIP в корень репозитория: `index.html`, `app.js`, `styles.css`, `data.js`, `config.js`, `database.sql`, `CNAME`, `.nojekyll`.
3. На https://supabase.com создайте проект. В SQL Editor выполните содержимое `database.sql`.
4. В Authentication → Providers включите Email; настройте подтверждение почты и Site URL/Redirect URLs для своего домена. Для публичного запуска настройте SMTP и ограничения отправки почты.
5. В Project Settings → API скопируйте Project URL и **publishable/anon** key в `config.js`. Никогда не используйте `service_role` или секретный ключ в браузере.
6. В GitHub Settings → Pages выберите Deploy from a branch → main → /(root), Save.
7. Для публикации на ymnichka.fun: в Settings → Pages укажите домен и убедитесь, что DNS уже направлен на GitHub Pages. Файл CNAME включён. При тестировании на другом репозитории временно удалите CNAME, иначе возникнет конфликт домена.
8. Проверьте регистрацию, письмо подтверждения, вход, первый тест и прогресс.

## Важно о безопасности и функциональности

Это статический клиент. GitHub Pages не выполняет серверный код. Supabase Auth и RLS защищают учётные записи и ограничивают доступ к данным пользователя.

**Ограничение:** ответы на тесты содержатся в публичном `data.js`; проверка и открытие уроков происходят в браузере. Это подходит для демонстрационного учебного MVP, но **не является защищённой серверной проверкой**: пользователь может подделать оценки и прогресс через API. Для честной аттестации необходимо вынести ответы, проверку и открытие уроков в Supabase Edge Functions, а права прямой записи в таблицы прогресса и результатов закрыть. Не используйте эту версию для сертификатов или официальных оценок.

Материалы уроков являются вводными конспектами и упражнениями, а не полноценным углублённым учебником. В проекте нет запуска Java в браузере.

## Структура
- `index.html` — точка входа
- `styles.css` — светлая тема и адаптивная верстка
- `app.js` — маршруты, авторизация, тесты и личный кабинет
- `data.js` — содержание 60 уроков и тестов
- `config.js` — публичные параметры Supabase
- `database.sql` — таблицы и RLS
- `CNAME` — ваш домен

Для локального просмотра запустите любой статический HTTP-сервер (например, `python -m http.server 8000`).
